# Тема: Реинжиниринг сервиса интеграции автомобильных объявлений для повышения отказоустойчивости

### Выполнил: Сиразетдинов Азат Ниязович, P3416
### Научный руководитель: Логинов Иван Павлович, доцент ФПИиКТ


# Задание

## Техническое задание
 
Реинжиниринг и внедрение сервиса интеграции автомобильных объявлений с использованием технологии Temporal для обеспечения устойчивости работы при сбоях.

## Цель работы

Повышение надежности сервиса интеграции автомобильных объявлений за счет использования системы оркестрации бизнес-процессов Temporal.

## Задачи работы

Провести анализ существующего сервиса интеграции автомобильных объявлений и выявить основные причины сбоев в его работе.Разработать архитектуру нового сервиса на основе оркестратора бизнес-процессов Temporal.Разработать механизм интеграции автомобильных объявлений в рамках новой архитектуры.Провести интеграционное тестирование нового сервиса и выполнить сравнение с существующим решением на предмет соответствия функциональным требованиям.Провести экспериментальную проверку системы и оценить влияние новой архитектуры на надежность сервиса.
